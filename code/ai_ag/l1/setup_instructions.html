# Install signing key sudo apt-get install wget gpg wget -qO- https://packages.microsoft.com/keys/microsoft.asc | gpg --dearmor > microsoft.gpg sudo install -D -o root -g root -m 644 microsoft.gpg /usr/share/keyrings/microsoft.gpg rm -f microsoft.gpg # Add repository and install sudo apt install apt-transport-https echo "deb [signed-by=/usr/share/keyrings/microsoft.gpg] https://packages.microsoft.com/repos/code stable main" | sudo tee /etc/apt/sources.list.d/vscode.list sudo apt update sudo apt install code
# Import key and add repository sudo rpm --import https://packages.microsoft.com/keys/microsoft.asc echo -e "[code]\nname=Visual Studio Code\nbaseurl=https://packages.microsoft.com/yumrepos/vscode\nenabled=1\nautorefresh=1\ntype=rpm-md\ngpgcheck=1\ngpgkey=https://packages.microsoft.com/keys/microsoft.asc" | sudo tee /etc/yum.repos.d/vscode.repo > /dev/null # Install VS Code dnf check-update sudo dnf install code
sudo snap install --classic code

Create a Linux Virtual Machine

VM Specifications

Resource Minimum Recommended
CPU Cores 4 vCPUs 16 vCPUs
RAM 20 GB 64 GB
Storage 50 GB SSD 100+ GB SSD
OS Ubuntu 22.04 LTS or Ubuntu 24.04 LTS
Running large language models locally requires significant RAM. The qwen3-coder:30b model alone requires ~19GB of storage and benefits from having ample memory for inference.

Choose Your Platform

Step 1: Enable Hyper-V

  1. Click the Start button and type "Turn Windows features on or off".
  2. Select the result to open the Windows Features window.
  3. Find Hyper-V in the list and check the box (ensure both "Hyper-V Management Tools" and "Hyper-V Platform" are selected).
  4. Click OK and restart your computer if prompted.

Step 2: Create the Virtual Machine

  1. Open Hyper-V Manager from the Start menu.
  2. In the Actions pane (right side), click New > Virtual Machine...
  3. Specify Name and Location: Name it "AI-Agent-VM".
  4. Specify Generation: Select Generation 2 (Recommended for modern OS).
  5. Assign Memory: Enter 20480 MB (20 GB) or more. Uncheck "Use Dynamic Memory" for better performance with LLMs.
  6. Configure Networking: Select "Default Switch".
  7. Connect Virtual Hard Disk: Create a virtual hard disk with size 50 GB or more.
  8. Installation Options: Select "Install an operating system from a bootable image file" and browse to your downloaded Ubuntu ISO.
  9. Finish the wizard and start the VM.

Reference: Microsoft Learn - Create a VM in Hyper-V

Using KVM/QEMU (Recommended for Linux)

Since you are on Linux, KVM provides the best performance as a native hypervisor.

# 1. Install KVM and tools sudo apt update sudo apt install qemu-kvm libvirt-daemon-system virt-manager # 2. Add your user to the libvirt group (requires logout/login) sudo usermod -aG libvirt $USER # 3. Start the Virtual Machine Manager GUI virt-manager
  1. In Virtual Machine Manager, click "Create a new virtual machine".
  2. Select "Local install media" and browse to your Ubuntu ISO.
  3. Memory & CPU: Set Memory to 20480 MiB and CPUs to 4.
  4. Storage: Create a disk image of 50 GB.
  5. Follow the prompts to finish installation.

💰 AWS Free Tier

New customers get up to 750 hours of t2.micro/t3.micro, but this is NOT enough for this course. You will incur costs for the r5.xlarge instance (approx $0.25/hour). Remember to STOP the instance when not in use.

Step 1: Launch Instance

  1. Log in to the AWS EC2 Console.
  2. Click the orange Launch Instance button.
  3. Name: Enter "AI-Agent-VM".
  4. Application and OS Images: Select Ubuntu (Server 22.04 LTS).
  5. Instance Type: Select r5.xlarge (4 vCPU, 32 GiB Memory).
    Note: You may need to request a quota increase if this type is not available to you.
  6. Key pair (login): Select "Proceed without a key pair" (We will use password auth).

Step 2: Configure Authentication (Crucial)

AWS disables password authentication by default. We will enable it using a startup script.

  1. Scroll down to Advanced details and expand it.
  2. Scroll to the bottom to the User data field.
  3. Copy and paste the following script exactly:
#!/bin/bash # Set password for 'ubuntu' user echo "ubuntu:YourStrongPassword123!" | chpasswd # Enable Password Authentication in SSH sed -i 's/PasswordAuthentication no/PasswordAuthentication yes/' /etc/ssh/sshd_config sed -i 's/Include \/etc\/ssh\/sshd_config.d\/\*.conf/#Include \/etc\/ssh\/sshd_config.d\/\*.conf/' /etc/ssh/sshd_config # Restart SSH service service ssh restart
Replace YourStrongPassword123! with your own secure password.

Step 3: Network Settings

  1. Ensure "Allow SSH traffic from" is checked.
  2. Click Launch instance.

Reference: AWS EC2 Get Started Guide

Authentication Note: We use password authentication in this guide for simplicity. If you are comfortable managing SSH keys and prefer the enhanced security, you may choose "SSH public key" as the authentication type.

3

Connect VS Code to the VM

Step 3.1: Install Remote - SSH Extension

To develop on the remote VM, you need the Remote - SSH extension by Microsoft.

  1. Open the Extensions view in VS Code (Click the square icon on the left sidebar or press Ctrl+Shift+X).
  2. Search for Remote - SSH.
  3. Click the Install button.

Step 3.2: Connect to Host

  1. Open the Command Palette (Ctrl+Shift+P or F1).
  2. Type and select: Remote-SSH: Connect to Host...
  3. Enter your connection string in the format username@ip-address (e.g., ubuntu@34.201.10.55) and press Enter.
  4. Select Linux as the platform if prompted.
  5. Enter your password in the prompt at the top of the window.
Once connected, a green indicator will appear in the bottom-left corner of VS Code showing the remote hostname (e.g., SSH: 34.201.10.55).
4

Install Extensions on Remote Server

Now that you are connected to the remote VM, you need to install extensions on the remote server to enable development features. VS Code manages extensions separately for your local machine and the remote host.

Step 4.1: Verify Remote Connection in Extensions View

Open the Extensions view (Ctrl+Shift+X). You will see a new section titled SSH: [Your IP] - Installed.

Step 4.2: Install Python Extension

  1. Search for Python (Microsoft).
  2. Click Install in SSH: [Your IP].

This enables IntelliSense, debugging, and Jupyter support directly on the VM.

Step 4.3: Install Live Preview Extension

  1. Search for Live Preview (Microsoft).
  2. Click Install in SSH: [Your IP].

This allows you to host and preview web files from the remote VM in your local VS Code.

5

Install Ollama and Download Models

Perform these steps in the VS Code Integrated Terminal connected to your remote VM.

Step 5.1: Install Ollama

curl -fsSL https://ollama.com/install.sh | sh

Verify installation:

ollama --version

Step 5.2: Download Required Models

1. Nomic Embed Text (Embedding Model)

ollama pull nomic-embed-text:latest

2. Qwen3-Coder (Code Generation Model)

ollama pull qwen3-coder:latest
Ensure your VM has sufficient disk space (approx 20GB for models) and RAM.

Step 5.3: Verify Installation

ollama list

Expected output:

NAME SIZE nomic-embed-text:latest 274 MB qwen3-coder:latest 19 GB
