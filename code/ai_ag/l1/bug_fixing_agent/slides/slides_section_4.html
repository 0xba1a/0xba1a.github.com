& Security

Agenda

Why Sandbox?

Agents execute code. Malicious or buggy agents can destroy systems.

Overlay Mounts

Protecting the original codebase.

  • Mount the code as Read-Only (Lower Dir).
  • Create a Writable Layer (Upper Dir) for the agent.
  • Agent sees a unified view but writes only to the disposable layer.
  • Original files remain untouched.

Kata Containers

Lightweight VMs for stronger isolation than standard Docker containers.

Prevents "Rogue Agents" from escaping to the host kernel.
