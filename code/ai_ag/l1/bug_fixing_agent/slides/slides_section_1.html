Level 1: Traditional Automation

Simple, rule-based systems. The current standard.

Example: A script to restart a server if memory > 90%.


def check_server():
    memory = get_memory_usage()
    if memory > 90:
        restart_server()  # Hard-coded rule
    else:
        log("All good")

Characteristics: Deterministic, Rigid, Predictable.

Level 2: LLM-Enhanced Automation

Using LLMs to convert Unstructured Data → Structured Data.

Example (Module 1): Checking if a joke is "Safe for Work".

graph LR A[Unstructured Joke] -->|LLM Extraction| B{Is Safe?} B -->|Yes| C[Email to Team] B -->|No| D[Discard] style A fill:#f9f,stroke:#333,stroke-width:2px style B fill:#bbf,stroke:#333,stroke-width:2px style C fill:#bfb,stroke:#333,stroke-width:2px
  • LLM Role: Information Extractor / Classifier.
  • Logic: Still hard-coded (If Safe → Email).
  • Nature: Deterministic decision making.

Level 3: AI Agents

Dynamic decision making with Tools & Heuristics.

How it works

  • LLM given Goal + Tools.
  • No pre-defined flow.
  • LLM decides the "Trajectory".
  • Fully Autonomous.

Risks & Rewards

  • Reward: Can find novel, optimized solutions.
  • Risk: Undeterministic. Can cause damage if guardrails fail.
  • Our Job: Provide Data, Tools, and Guardrails.

Goal: "Fix the bug."
Trajectory 1: Read File -> Think -> Edit -> Test (Pass)
Trajectory 2: Read File -> Think -> Search StackOverflow -> Edit -> Test (Pass)

Architecture: Simple Bug Fixing Agent

The Setup:

  • Data: A file containing buggy code.
  • Prompt: "You are an engineer. Fix the bug."
  • Tools: Bash Terminal (cat, python, grep, sed).

The Loop:

  1. Observation: Read file / Run code.
  2. Thought: Analyze error / Plan fix.
  3. Action: Execute bash command.
graph TD A[Start: Buggy Code] --> B(Observation) B --> C{Thought} C -->|Need Info/Fix| D[Action: Bash Command] D -->|Output/Error| B C -->|Fixed| E((Finish)) style B fill:#ff9,stroke:#333 style C fill:#9f9,stroke:#333 style D fill:#99f,stroke:#333

Components of an Agent

  • Prompt (Persona): "You are a bug fixer..."
  • LLM (Brain): Reasoning engine.
  • Environment: Where it lives (Terminal, File System).
  • Action Loop: Observe → Think → Act.
