Self-Reflection Pattern

Agents shouldn't just act; they should critique their own work.

"I wrote this code. Does it actually solve the problem? Are there edge cases?"

LLM-Based Grader

Using an LLM to evaluate the output of another LLM.

  • Check for logic errors not caught by linters.
  • Verify adherence to style guides.
  • Ensure the solution matches the user intent.
