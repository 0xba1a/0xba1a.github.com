Agentic Design Patterns

Common architectural approaches for building AI agent systems

1. Single-Agent Pattern

graph TD U[User] --> A[Agent] A --> M[AI Model] M --> A A --> T1[Tool 1] A --> T2[Tool 2] A --> T3[Tool 3] A --> U style A fill:#9cf,stroke:#333,color:#000 style M fill:#fc9,stroke:#333,color:#000

When to use: Multi-step tasks with external tools, early prototyping

Trade-offs: Simple to implement, but less effective with many tools

2. Sequential Pattern

graph LR A1[Agent 1] --> A2[Agent 2] A2 --> A3[Agent 3] A3 --> O[Output] style A1 fill:#9cf,stroke:#333,color:#000 style A2 fill:#9fc,stroke:#333,color:#000 style A3 fill:#fc9,stroke:#333,color:#000

When to use: Highly structured pipelines, data processing workflows

Example: Extract → Clean → Load (ETL pipeline)

3. Parallel Pattern

graph TD I[Input] --> A1[Agent 1] I --> A2[Agent 2] I --> A3[Agent 3] A1 --> G[Gather] A2 --> G A3 --> G G --> O[Output] style A1 fill:#9cf,stroke:#333,color:#000 style A2 fill:#9fc,stroke:#333,color:#000 style A3 fill:#fc9,stroke:#333,color:#000 style G fill:#f9c,stroke:#333,color:#000

When to use: Independent sub-tasks, reduce latency, gather diverse perspectives

Example: Sentiment + Keywords + Category analysis in parallel

4. Loop Pattern

graph TD S[Start] --> A[Agent] A --> C{Exit Condition?} C -->|No| A C -->|Yes| O[Output] style A fill:#9cf,stroke:#333,color:#000 style C fill:#fc9,stroke:#333,color:#000

When to use: Iterative refinement, self-correction until quality threshold met

⚠️ Risk: Infinite loops if exit condition fails

5. Review & Critique Pattern

graph TD G[Generator] --> C[Critic] C -->|Approve| O[Output] C -->|Reject| G style G fill:#9cf,stroke:#333,color:#000 style C fill:#f9c,stroke:#333,color:#000 style O fill:#6f6,stroke:#333,color:#000

When to use: High accuracy requirements, strict constraints, security auditing

Example: Code generation + Security review

6. Coordinator Pattern

graph TD U[User] --> C[Coordinator] C -->|Route| A1[Agent 1] C -->|Route| A2[Agent 2] C -->|Route| A3[Agent 3] A1 --> C A2 --> C A3 --> C C --> U style C fill:#fc9,stroke:#333,color:#000 style A1 fill:#9cf,stroke:#333,color:#000 style A2 fill:#9fc,stroke:#333,color:#000 style A3 fill:#f9c,stroke:#333,color:#000

Key Feature: AI model orchestrates routing dynamically

When to use: Dynamic task routing, varied input types, customer service bots

7. Hierarchical Task Decomposition

graph TD R[Root Agent] --> M1[Manager 1] R --> M2[Manager 2] M1 --> W1[Worker] M1 --> W2[Worker] M2 --> W3[Worker] M2 --> W4[Worker] style R fill:#fc9,stroke:#333,color:#000 style M1 fill:#9cf,stroke:#333,color:#000 style M2 fill:#9cf,stroke:#333,color:#000

When to use: Complex ambiguous problems, multi-step reasoning, research tasks

Trade-off: High latency & cost

8. Swarm Pattern

graph TD D[Dispatcher] --> A1[Agent 1] D --> A2[Agent 2] D --> A3[Agent 3] A1 <--> A2 A2 <--> A3 A1 <--> A3 style D fill:#fc9,stroke:#333,color:#000 style A1 fill:#9cf,stroke:#333,color:#000 style A2 fill:#9fc,stroke:#333,color:#000 style A3 fill:#f9c,stroke:#333,color:#000

Key Feature: All-to-all communication between agents

When to use: Collaborative debate, creative solutions, multiple perspectives

⚠️ Most complex pattern

9. ReAct Pattern (Reason + Act)

graph TD T[Thought] --> A[Action] A --> O[Observation] O --> T O -->|Done| R[Result] style T fill:#9cf,stroke:#333,color:#000 style A fill:#fc9,stroke:#333,color:#000 style O fill:#9fc,stroke:#333,color:#000

Iterative Loop: Thought → Action → Observation → Repeat

Use for: Complex, dynamic tasks requiring reasoning

10. Human-in-the-Loop Pattern

graph TD A[Agent] --> C{Checkpoint} C --> H[Human Review] H -->|Approve| N[Next Step] H -->|Reject| A N --> A style A fill:#9cf,stroke:#333,color:#000 style H fill:#fc9,stroke:#333,color:#000 style C fill:#f9c,stroke:#333,color:#000

When to use: High-stakes decisions, safety-critical operations, compliance

Choosing the Right Pattern

Workflow Type Recommended Pattern
Deterministic, fixed steps Sequential, Parallel
Dynamic routing needed Coordinator, Single-Agent
Iterative refinement Loop, Review & Critique, ReAct
Complex, ambiguous Hierarchical, Swarm
Human oversight required Human-in-the-Loop
